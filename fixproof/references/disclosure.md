# Disclosure

## Third-party components

None. The skill package contains only original Markdown files. It calls no external service and downloads nothing. All work runs through the NAS's own expert agents: file-agent, photo-agent, document-agent and knowledge-agent.

## Data flows

User documents are read on the NAS by the NAS's expert agents. The only data written is a claim draft or warranty calendar note, saved on the NAS through knowledge-agent after the user approves it. No data is sent outside the NAS by this skill.

## Developed for this hackathon

The skill's concept, workflow, coverage rules, answer format and examples were written for the UGREEN AI NAS Hackathon 2026 by the entrant.

## AI tools used

Claude (Anthropic) was used as a writing and review assistant: to draft and edit the Markdown, to check the package against the published Skill rules, and to generate the fictional test documents used for validation. The entrant reviewed and is responsible for all content.

## Test data

All brands, stores, people, model numbers and serial numbers in the examples and test library are fictional.
